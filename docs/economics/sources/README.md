# Source texts

Plain-text extractions (pypdf) of public documents used to parameterize SURGE, kept so the
config and tests can be reproduced without re-downloading. Originals:

- `ferrier-saavoss-williamson-2024.txt`: Ferrier, Saavoss, Williamson (2024), Welfare Effects of the 2022 U.S. HPAI Outbreak, NCCC-134. https://farmdoc.illinois.edu/assets/meetings/nccc134/conf_2024/pdf/Ferrier_Saavoss_Williamson%20NCCC-134%202024.pdf
- `mitchell-thompson-malone-2025-fryar.txt`: Fryar Center FC-2025-001. https://fryar-risk-center.uada.edu/files/2025/02/2024-HPAI-Impacts-Egg-Prices.pdf
- `ers-err57-appendix-b.txt`: Paarlberg et al. (2008), ERS ERR-57 Appendix B. https://www.ers.usda.gov/media/14522/appendix-b-numerical-model-data-and-numerical-form.pdf
- `aphis-2022-2023-depopulation-analysis.txt`: APHIS HPAI 2022–2023 depopulation analysis. https://www.aphis.usda.gov/sites/default/files/hpai-2022-2023-summary-depop-analysis.pdf
- `packages/config/tools/err139.txt`: Okrent & Alston (2012), ERS ERR-139 (used by the elasticity extraction script). https://www.ers.usda.gov/sites/default/files/_laserfiche/publications/45003/30438_err139.pdf
